## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于赛前、进行、完赛、官宣还是复盘阶段”。然后从以下 7 类中选择最贴近的一类：

- `match_report`：赛果、比分、关键对局与系列赛进程
- `roster_move`：转会、大名单、教练变动、退役复出
- `patch_update`：游戏版本更新、英雄调整、赛场环境变化
- `league_business`：赛制、赛程、联盟公告、席位、商务与俱乐部经营
- `tactical_analysis`：BP 解读、战术体系拆解、英雄克制与运营复盘
- `tutorial_explainer`：可上手的打法教学、出装铭文思路（限与赛场相关的）
- `opinion_analysis`：观点、预测、访谈或解说评论

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在 KPL 时间线上是节点、这周值得知道的变化，还是当天脚注。季后赛胜负、冠军归属、明星转会是大节点；常规赛中段的普通胜场按阶段打折。不要把“讨论度高”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。确切的比分与数据、确认的转会去向、版本具体改动、新的战术事实才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方公告足以证明“官宣、赛果、版本上线”这一动作，但不能自动证明传言或效果宣称。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关，或至少能理解它为何重要、反常、好玩。争冠形势、豪门对决、明星选手、赛制变化覆盖面广；中下游队伍的例行轮换覆盖面窄。
5. `act` 可用性：读者是否能马上据此调整理解——更新战队实力认知、修正对版本 BP 的判断、决定是否追赛。纯赛果的 act 低是正常的，不应反过来抹掉 sig。

## 品味规则

### 必须正常评价的价值

- 季后赛与总决赛的赛果、冠军与 FMVP 归属、关键对局的真实过程（比分之外的翻盘点、BP 博弈、经济曲线）。
- 争冠级选手或明星选手的转会、退役、复出；彻底改变一支战队实力格局的阵容变动。
- 显著改变赛场环境的版本更新：数值大改、机制变化、新英雄上线对 BP 的影响。
- 赛制变化、晋级形势的实质变化、联盟重大公告（版权、席位、赛程体系）。
- 具体可复用的战术认知：BP 思路、克制关系、体系拆解，只要讲清楚事实与理由，即使不是爆点新闻也可以高分。
- 可信的新事实、反直觉结果、数据里程碑（选手千杀、出场纪录）、人物信号、文化反差，只要普通读者一眼能理解“为什么有意思”。

### 必须压住的噪声

- 常规赛一场无关排名走向的比赛的纯比分播报，没有关键过程与数据，`sig ≤ 3`。
- 俱乐部日常运营、周边商品、粉丝活动、商务挂牌，没有竞技层面后果，`sig ≤ 2`。
- 小幅数值调整、皮肤上线、主播互动、平台活动，`sig ≤ 3`。
- 只有赛前预告、海报或“敬请期待”，没有确定事实，`nov ≤ 3` 且 `cred ≤ 4`。
- 自媒体只说“状态神勇、大局已定”，没有比分、数据或过程，`nov ≤ 3` 且 `sig ≤ 4`。
- 每日赛程汇总、多场比分打包且无单一焦点，`sig ≤ 3`。
- 挂靠赛事的博彩、饭圈互撕、无事实依据的八卦传闻，`sig ≤ 2` 且 `cred ≤ 2`。
- 宏大观点若没有新事实或新因果；仅“谁更强”的情绪站队；路人局战绩与 rank 分，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的比分、转会费或因果补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”（如转会传闻），却无法确认官宣或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 官方确认本身就是实质变化。一条官宣转会、一份大名单、一场已确认的赛果，即使材料是短公告，也不能按“个人二手体验”或“普通转发”压低 `sig`、`nov`、`reson`。
3. 完整对局数据（BP 时序、选手 KDA、经济与资源）让赛果报道同时成为可分析的事实；不得套用“纯比分播报”的上限，也不得因为数字多就自动豁免噪声。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“夺冠官宣 + 一句感谢”“关键战报 + 粉丝互动”，不能只抓住后者。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一传闻或情绪站队制造事件价值。只有正文支持的新事实、赛果变化或可迁移打法认知进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
