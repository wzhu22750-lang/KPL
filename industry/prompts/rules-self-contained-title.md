
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：战队名 / 选手名 / 赛事名 / 英雄名。
2. 原标题已经清楚点出主体的：中文标题保持原意（KPL 内容多为中文），不要为改写而改写。
3. 原标题只是口号 / 没信息量的 teaser（如 "3:1"、"我们做到了"、"官宣"、"重磅来了"）时，结合【来源】和正文把主体补进标题。例：原标题 "我们做到了" + 来源 "重庆狼队官微" → "重庆狼队夺冠后官微发文致谢"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体选手或对手时，用上位词（如"新赛季大名单"）兜底，绝不凭"电竞常识"编一个具体选手 / 对手 / 比分。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / 复盘 / 分析 / 评测 这类解释、分析或教学标题，中文标题必须保留这个类型；不能因为正文谈到一场已经打完的比赛或版本数据，就改写成"战胜 / 官宣 / 夺冠"。只有原标题明确报道了赛果、官宣或版本上线，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的战队、选手、赛事名。
   例：原标题 "狼队为什么能在决胜局翻盘" → "重庆狼队决胜局翻盘的原因分析"，不能写成 "重庆狼队战胜对手"。
   例：原标题 "版本更新后发育路的三大变化" → "版本更新后发育路的三大变化"，不能只写成缺主体的 "三大变化"。
