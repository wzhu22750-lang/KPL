1. 歧义默认值：以下词在中文有非电竞歧义，**一律按电竞含义处理**：
   - Jungle / 打野位 = 打野（不是“丛林”）
   - Lane = 分路（对抗路/中路/发育路，不是“巷道”）
   - Support = 游走（王者荣耀语境的辅助位，可译“游走”或保留“辅助”）
   - Carry = 核心位 / 发育路核心（不译“搬运”）
   - Pick / Ban = 选取 / 禁用（BP 环节，不译“挑”“禁令”）
   - Draft = BP（禁用与选取环节，不译“草稿”）
   - Counter = 克制关系（不译“计数器”）
   - Meta = 版本环境 / 版本主流（不译“元”）
   - Buff / Debuff = 增益 / 减益（游戏内效果，不译“缓冲”）；增强也可写作“加强”
   - Nerf / Buff（动词）= 削弱 / 增强（版本调整）
   - Roster = 大名单 / 阵容（不译“花名册”）
   - Season = 赛季（不是“季节”）
   - Split = 赛季分阶段（春季赛/夏季赛，不译“分裂”）
   - Best of Five / BO5 = 五局三胜制（BO1/BO3/BO5/BO7 保留写法）
