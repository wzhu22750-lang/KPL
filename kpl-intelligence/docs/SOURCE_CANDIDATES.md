# KPL 信源候选清单（SOURCE_CANDIDATES）

本文件记录**曾经尝试、但当前无法稳定接入**的 KPL 信源。每条都写明：价值、实测过程、失败原因、未来接入方式。
原则（§37）：不伪造接口、不写 hack、不用高度脆弱的逆向路径充数——不能稳定获取的就停在这里，由
`source_discovery_queue` 与后台"信源覆盖率"看板持续提醒，直到条件成熟再接入。

实测时间：2026-10-06（Asia/Shanghai）。

---

## 1. 微博（最高优先级缺口）

**目标**：KPL 联盟官方微博、各俱乐部官方微博、选手/教练认证账号——KPL 官宣的第一阵地（转会、大名单、处罚、首发）。

**实测过程**
- `https://m.weibo.cn/api/container/getIndex`（按 uid / 关键词）：直接返回 `302 → visitor.passport.weibo.cn`；
- 走完整访客流程（`passport.weibo.com/visitor/genvisitor` → `visitor?a=incarnate` → 带 `tid` Cookie 重试）：
  接口返回 **HTTP 432**（反爬拦截），访客态不可用；
- 移动端页面 `m.weibo.cn/u/<uid>` 亦强制跳转访客认证页，无 SSR 内容可解析。

**结论**：免登录程序化读取微博内容当前不可行。**不接入**。

**未来接入方式**（按优先级）
1. 登录态 Cookie / 官方开放平台授权（微博开放平台 API 需企业资质）；
2. 第三方数据服务（与 SocialData 同类的国内社媒数据商，走现有 `providers/receipts.ts` 付费网关即可接入，新增 reader 复用 `json_list` 或专用 adapter）；
3. 人工运营：后台手工录入/转发官方微博截图与要点（`ingest` 接口已支持外部提交）。

**验收影响**：微博缺失意味着"转会/处罚/首发"类官宣只能靠俱乐部公众号与 B 站补，
`sources/authority.ts` 的 league/club 权威已就位，微博一旦接入即刻生效。

## 2. 王者营地（腾讯生态内 KPL 资讯页）

**目标**：王者营地 KPL 资讯/赛事页——腾讯自有生态，若可用则是仅次于官方赛事数据的补充。

**实测过程**
- 无公开文档化的资讯 API；营地内容要求登录态与 App 内签名；
- 尝试的公开入口均无稳定 JSON 响应（`api.zwnd.cn` 等第三方镜像不可信，未采用）。

**结论**：**candidate / unsupported**。不写逆向签名接口（脆弱且违反 §11）。

**未来接入方式**：若腾讯开放平台提供电竞资讯接口，或通过官方合作渠道获取，再按 `json_list` 接入。

---

## 3. 抖音 / 快手 / 小红书

**目标**：KPL 官方与俱乐部在上述平台的赛事传播内容（剪辑、采访、即时热点）。

**实测过程**：三平台均需登录态与设备指纹签名（`X-Bogus`/`a_bogus` 等），无稳定免登录读取路径。

**结论**：**暂不接入**（§15：按"稳定性 + 信息增量"评估，不为平台数量强行采集）。

**未来接入方式**：官方开放平台（抖音开放平台企业号 API）或第三方数据服务；接入后默认 `participation_mode = hot_signal`，
仅当账号明确为 KPL/俱乐部/选手官方时才提升 first-party 权重。

## 5. 已实测可用、但需要登记的通道限制

| 通道 | 限制 | 应对 |
|---|---|---|
| B站 `x/series/recArchivesByKeywords` | 高频调用触发 **HTTP 412 风控**（本机压测后复现） | 生产节奏（120 min/源，错峰）足够；源自带退避重试与 health 降级 |
| B站 `x/space/wbi/arc/search` | 需 WBI 签名，免签名返回 `-352 风控校验失败` | 不使用；改用 `recArchivesByKeywords` |
| B站用户搜索 `wbi/search/type?search_type=bili_user` | 返回的粉丝数/认证字段在免登录下不可靠 | 仅用于**发现候选**，账号身份一律以空间页 SSR + 近期内容三重验证为准 |
| sogou 微信搜索 | 可解析但索引陈旧（多个俱乐部账号停在 2022-2024） | 仅作免费回退通道；活跃账号（TTG、KPL 官方）实测有近 7 日文章 |

## 6. 明确禁止接入（§27）

采集站、SEO 站群、机器洗稿号、自动转载号、无来源营销号、百度/搜狗搜索结果页、搜索引擎缓存、低质量门户转载：
不作为 editorial 信源。宁愿 60 个高质量来源，也不要 500 个垃圾站点。搜索引擎只能用于**发现信源**
（如本轮用其发现账号候选），永不作为 primary source。
