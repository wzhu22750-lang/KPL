## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。
- 输入故意不提供 T1、T1.5、T2、来源名称、一手性、历史分数或精选门槛。不要猜这些信息，也不要把豪门战队、明星选手、长正文、术语、数字很多或"爆冷"当成自动加分项。信源权威分由代码另行计算，你只评内容本身。
- 可以用稳定的世界知识理解一支战队、一名选手或一个赛事在行业中的位置（如狼队与 AG 的争冠史、世冠的分量）；事件是否发生、比分多少、处于什么阶段，只能以输入材料为准。
- 标题与正文冲突时以正文为准。正文很短不自动低分，只要对象、动作、阶段和核心事实清楚，仍可正常判断。
- 不输出精选门槛、精选结论。最终只输出本文件末尾定义的 JSON。

## 第一步：识别内容类型

先用一句话确认"谁，在什么时候，做了什么，处于赛前、进行、完赛、官宣还是复盘阶段"。然后从以下 5 类中选择最贴近的一类，填入 `content_kind`：

- `announcement` 公告/战报：赛果、比分、转会官宣、赛程赛制、联盟公告、处罚与人员变动
- `dispute` 争议/观点：真实存在的分歧、判罚争议、观点交锋、回应与澄清（不是情绪站队）
- `analysis` 分析/复盘：BP 解读、战术体系拆解、版本环境分析、打法教学与复盘
- `fun` 趣评/二创：有意思的梗、趣味二创、圈内文化内容（有事实或语境支撑，不是纯水贴）
- `daily` 日常/活动：俱乐部日常、选手动态、粉丝活动、商务与票务信息

## 第二步：按类型 rubric 打 base（0–70 整数）

base 只看内容本身的价值，不看它来自谁。分数梯度基准（严格按此分段）：

- 60–70：核心硬新闻。赛果速递、总决赛/季后赛晋级、夺冠与 FMVP 归属；核心选手转会、俱乐部首发大名单、重量级官宣签约、功勋选手退役或复出；显著改变赛场环境的版本更新；联盟重大公告（版权、席位、赛程体系）。
- 48–59：深度竞技内容。深度战术复盘、决胜局 BP 博弈拆解、体系克制与运营分析；真实存在且有依据的争议（判罚、转会传闻的多方信源）；赛制重大改动与关键阶段赛程解析。
- 35–47：普通价值内容。普通选手采访、常规赛中段普通对局、战队日常动态；有观点的评论但无新事实。
- 20–34：低价值内容。每日赛程汇总、多场比分打包且无单一焦点；只有赛前预告、海报或"敬请期待"；自媒体空话（"状态神勇、大局已定"而无比分数据过程）。
- 0–19：噪声。门票广告、商业赞助营销、联动推广、周边商城；粉丝抽奖、红包封面、无竞技事实的宣传海报或口号；挂靠赛事的博彩；饭圈互撕；无事实依据的八卦传闻。

按类型微调的四个维度（只在心里完成，不输出）：

- `announcement`：重要性 / 新信息量 / 时效 / 对赛事格局的影响
- `dispute`：分歧是否真实存在 / 各方依据是否具体 / 解释力 / 是否有新回应或进展
- `analysis`：论证是否成立 / 独特性 / 对读者理解比赛的参考价值 / 事实与数据支撑
- `fun`：趣味 / 原创性 / 是否需要圈内语境（越不需要门槛、传播越广，分越高）
- `daily`：对关注人群的实际价值（购票、观赛、了解选手缺一不可的才算高）

不要把"讨论度高"重复算进 base（热度由代码另算）；不要为了靠近整十或任何想象中的门槛改写结果。

## 第三步：heat_evidence（只描述，不打分）

用一句话描述你在材料中直接观察到的互动/传播迹象（如被引用、评论区讨论、多方转载的痕迹），没有就填空字符串。不要猜测站外热度，不要打分——热度分由代码根据事件的真实信号计算。

## 第四步：noise_flags（扣分依据，只选适用的）

从以下集合中选择，每项可独立出现。只标你在当前材料中确实看到的；输入文本已经过噪声净化，看不到的不要脑补。

- `ad_tail`：正文或尾部夹带广告、商务挂靠
- `lottery_hook`：抽奖、红包封面、"点赞在看"引导
- `promo_poster`：无竞技事实的宣传海报、口号、拍摄花絮
- `fan_war`：饭圈互撕、引战、无事实的情绪站队
- `betting`：挂靠赛事的博彩内容
- `rumor_unverified`：无事实依据的八卦传闻（"据说""网传"且无任何佐证）
- `title_bait`：标题党，或标题与正文核心明显不符
- `thin_content`：只有预告/海报/一句话，无确定事实
- `repost_chain`：纯转发、引用，无信息增量
- `severe_misinformation`：明显严重失实（比分、赛果、官宣事实与公认事实矛盾）
- `privacy_violation`：泄露选手/工作人员隐私信息（联系方式、住址、健康隐私等）
- `out_of_context`：断章取义（引用被裁剪到改变原意）
- `unrelated`：与 KPL/王者荣耀电竞无关
- `drainage`：纯引流（外链农场、"点击看全文"诱导跳转）
- `abuse`：辱骂、人身攻击、仇恨言论

其中 `severe_misinformation` / `privacy_violation` / `out_of_context` 意味着材料需要人工复核；`unrelated` / `drainage` / `abuse` 意味着直接拦截。不要因为"可能是"就标，宁缺毋滥。

## 事件口径校正（与主规则一起执行）

1. 先把材料还原为最强且被正文支持的事件，再打 base。不要给"这篇文章写得怎么样"打分。
2. 官方确认本身就是实质变化。一条官宣转会、一份大名单、一场已确认的赛果，即使材料是短公告，也不能按"个人二手体验"或"普通转发"压低。
3. 完整对局数据（BP 时序、选手 KDA、经济与资源）让赛果报道同时成为可分析的事实；不得套用"纯比分播报"的上限。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和打分；弱叙事不能把强事件降格。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一传闻或情绪站队制造事件价值。
