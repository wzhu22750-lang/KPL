# 信源盘点与质量优化清单

> 本轮盘点的是仓库种子配置，不是线上数据库实际启用状态。已修正身份分类和同事实战报代表排序，完成小范围公开网页试抓；没有安装新信源、启用评论采集、迁移生产库或覆盖赛事数据。

## 结论：先分工，再补人，最后扩社区

1. **微博联盟官方战报负责“发生了什么”**：作为赛事胜负、比分的编辑主出处，不让二路观点、俱乐部庆祝帖或 B 站回放抢同一赛果的主报道位置。
2. **B 站官方视频负责“回看发生的过程”**：官方完整回放、逐局回放、集锦、采访分开标，不把所有官方视频都叫回放。
3. **二路、选手、主播负责“不同主体怎么看”**；超话、虎扑、二创与评论负责“观众在讨论什么”。高互动是选题线索，不是事实背书。
4. 不追求账号总量：先补微博选手和主播空白，再补俱乐部覆盖，最后扩大社区召回。

## 所有平台统一身份，不按平台猜人

平台、发布者身份、内容用途是三个维度：`B站 × 官方 × 回放`、`微博 × 选手 × 赛后感言`、`虎扑 × 观众 × 评论`。

| 核心身份 | 子类 / 边界 | 适合入选的内容 |
|---|---|---|
| 官方 | 联盟官方、俱乐部官方分别保留 | 联盟战报/规则；俱乐部自身首发、阵容、声明 |
| 二路 | 二路/解说；个人账号不因“官方解说”头衔成为联盟官方 | 有具体比赛节点、原话或时间戳的解释和争议观点 |
| 选手 | 选手本人；教练/工作人员保留子类 | 第一人称赛后反馈、训练与职业动态；本人身份仍需核验 |
| 主播 | 非二路内容为主的直播创作者 | 与当场比赛有关的独立观点，不泛收日常开播广告 |
| 观众 | 普通帖子、回复、二创作者；身份未知时不猜职业身份 | 原创分析、实质讨论、具代表性的趣评/二创 |

媒体/创作者保留独立兜底，不强塞进“观众”。当前实现仍为来源级单一分类：官方、战队官方、选手/教练、二路/解说、主播、媒体/创作者、观众/社区。Gemini 这类同时有二路和主播标签的账号优先归二路；选手兼直播优先归选手。

**尚未解决的关键边界**：关键词搜索、论坛聚合流里的每个作者身份不一定相同。当前 `source.group` 是入口分类，不是对所有帖作者的认证。后续应按平台作者ID关联已核验账号目录；无法匹配则显示“社区入口·作者身份未核验”。搬运选手直播的UP仍是搬运者，不能标成选手本人；官方帖子下面的普通评论也不能继承官方身份。

## 微博与B站的明确分工

| 内容 | 主出处 | 其他来源如何使用 | 展示目标 |
|---|---|---|---|
| 赛果、比分 | KPL联盟官方微博战报 | B站回放作佐证与观看入口；冲突待核验 | 同一赛果一张主卡，标“官方战报·微博” |
| 完整比赛过程 | 已核验官方B站账号的对应场次视频 | 核对赛季、对阵、日期、局数；缺局明示 | “官方回放·B站”，区分整场/第N局/集锦 |
| 首发、阵容、自身声明 | 对应俱乐部官宣/联盟名单 | 本人反馈补充，主播转述不能替代 | “俱乐部官方”，不要泛写联盟官方 |
| 赛后解释和反应 | 二路/选手/主播原帖或原视频 | 搬运追溯原话、时间戳与上下文 | 观点署名；与赛果正文分层 |
| 观众讨论和二创 | 原帖、原评论、原视频 | 只读摘要和短引用；保留原文链接 | “观众讨论/二创”，不写成已证实新闻 |

目标赛事卡：官方战报 → 官方回放 → 二路观点 → 选手/主播回应 → 观众精选。没有某一层就显示缺失或不展示，不用低质量材料填满。

本轮已实现**同一已归组赛果**内联盟微博优先选代表报道：要求 `fact.claim_type=match_result`、微博采集源、league/kpl归属、UID `6074356560` 同时匹配。不是仅凭“T1”“官方”标题或平台名称加分。仍遵循调用方原有精选/公开/时间窗口；没有符合条件的微博候选则沿用旧排序，不编造战报。

这不是自动识别/配对B站回放，也不是把微博文字直接写进 `matches` 比分。回放完整性分类、场次配对和上述分层赛事卡仍待实现。

### 高互动如何筛，不变成情绪搬运

- **候选召回**：近期相关比赛窗口 + 平台内热榜/互动；保留新帖窗口，避免只有老热视频。播放量、点赞、评论数分开，不把B站搜索totalrank称为高赞排序。
- **帖子与评论分别计量**：记录帖子ID、评论ID、父评论ID、作者平台ID、原链接、发布时间、观测时间、真实赞/评数及覆盖范围。未知计数为未知，不补零。
- **同平台同类比较**：微博点赞、虎扑点亮、B站评论赞不直接相加排名。新旧帖子分窗口，热度只用于候选排序，不更改事实权威。
- **内容门禁**：优先具体论点、可追溯比赛片段、原创解释和有语境的幽默；排除刷屏、引战人身攻击、重复应援、广告。热点指控回查原声明，不能把多次转述算多份证据。
- **选样呈现**：同梗/搬运去重；展示不同有信息量的观点，不做机械赞踩对半。每场少量精选，附为何选、原上下文及“高赞样本，不代表全体观众”。
- **版权与隐私**：默认摘要、短引用和原链接；不整段搬视频或评论，不扩散个人隐私。删除/不可访问的内容不持续当作可核验证据。

仓库已有 `community-comments.ts`（微博/B站受控评论入口）与虎扑正文/回复解析器，优先复用，不另起全量爬虫。现有能力文档对“评论未接通”的表述应理解为生产配置/验证缺口，并非完全没有相关代码。本轮未配置真实评论端点或打开采集开关。

后续按顺序推进：

2. 核验并安装选手、主播、缺失俱乐部账号；确保每一类有有效内容，空标签不等于覆盖完成。
