## 二、地图机制与对局运营专业术语

### 1. 野区博弈（Jungle Dynamics）
- **红区 / 蓝区**：红BUFF（猩红石像，攻击附带减速与灼烧真实伤害）与蓝BUFF（蔚蓝石像，提供20%冷却缩减与持续回蓝）分布的半区。
- **反野 / 进野区 / 偷野**：利用前期对线优势、英雄强势期或抱团优势强行入侵敌方野区，掠夺野怪与BUFF资源，压制敌方打野发育。
- **守野区 / 保野区**：防守方在队友提前占视野与支援下保护己方野怪资源，防止敌方反野滚起经济雪球。
- **换野区**：双方各自入侵对方对应半区（如以红换红、以蓝换蓝）互换野区资源。
- **野区保护机制**：前4分钟敌方英雄进入己方野区受到减伤削弱影响。
- **野区经济分配**：野核吃全部野区与中线；蓝领野让出红蓝BUFF与小野怪给双C。

### 2. 中立生物与龙坑争夺（Objectives）
- **开龙 / 动龙 / 拿龙 / 控龙**：主动对中立生物（暴君、主宰、风暴龙王）发起进攻。通常在造成敌方减员、推掉外塔或敌方回城时开启。
- **抢龙 / 拼龙 / 拼惩戒**：在残血时利用高爆发技能或召唤师技能【惩击】抢夺龙属性Buff，是逆风翻盘的兵家必争胜负手。
- **暴君 / 黑暴 / 暗影暴君**：提供全队金币与额外伤害增益，强化正面团战输出。
- **主宰 / 暗影主宰 / 暗影先锋 / 龙兵**：击杀后召唤主宰先锋（龙兵）或使用暗影先锋，提供推塔线权优势与兵线运营主动权。
- **风暴龙王 / 龙王团 / 决胜龙王**：20分钟刷新的终极中立生物，提供高额雷击护盾与感电伤害，是后期决胜团战的核心争夺点。
- **龙坑逼团 / 龙坑拉扯**：假打龙真开团，逼迫对方进草探视野接团。
- **放龙**：在局势劣势或人员不齐时主动放弃争夺远古生物，转而去带边线或止损。

### 3. 兵线与推塔运营（Wave & Siege）
- **线权 / 抢线权 / 抢线**：优先清线的一方拥有线权，可率先脱离线上争夺，转线游走支援或入侵野区。
- **转线**：推完一路后快速移动至其他分路形成局部人数优势。
- **四一分带 / 带线**：四人正面牵制，一人单挑或逃生能力强的英雄（老夫子、马超、芈月）单独带线推塔。
- **控线 / 卡线**：将兵线卡在己方防御塔外安全位置，阻碍敌方吃线发育并制造Gank机会。
- **断线**：绕到敌方高地塔外提前清兵，瓦解敌方推进攻势。
- **拔塔 / 拔外塔 / 拔二塔 / 破高地**：逐步推毁敌方外塔、二塔或高地防御塔。破高地后将刷新高攻高血量的超级兵。
- **运线 / 卡三路兵线**：调整各路兵线进塔时机，使三路兵线同时到达敌方高地，迫使敌方顾此失彼无法集中防守。
- **偷家 / 偷水晶**：正面团战牵制时，利用单人或大乔电梯快速直捣敌方水晶。

## 三、团战与战术执行黑话（Combat & Execution）

### 1. 战术动作
- **开团 / 强开 / 先手**：主动释放强控技能或位移发起团战（如白起嘲讽、鬼谷子拉、鲁大拉、廉颇大招）。
- **反打 / 接团**：承受对方第一波技能后，借助保命装、减伤或后手群控进行强力反击。
- **拉扯 / 避战**：保持安全身位并利用技能射程与加速机制反复消耗，诱导敌方交出核心技能。
- **拆火**：核心输出遭到突进时，队友利用击飞/击退/眩晕/封路打断敌方输出链，护送核心撤离或反杀。
- **掉点**：选手因站位失误、脸探草丛等非团战非迫性原因阵亡，导致团队在后续时间内处于以少打多劣势。
- **脱节**：前排开团冲入敌阵而后排输出跟不上，或后排被切前排无法回援。
- **起节奏 / 断节奏**：打出关键击杀或推塔破局带动全场攻势（起节奏）；失误被抓或被反打导致攻势停滞（断节奏）。
- **残局**：大规模团战技能交尽、双方减员后的收割与拉扯阶段。

### 2. 视野机制
- **视野压制 / 占视野**：辅助与坦克提前站住中草、河道草排查隐患并给队友提供敌方动向。
- **卡视野**：利用战争迷雾（视野盲区）进行走位欺骗。
- **探草**：使用远距离技能（如沈梦溪炸弹、百里守约一技能眼、王昭君一技能）探测草丛内是否有伏兵。
- **蹲草**：多人隐蔽在草丛伏击敌方路过人员。

## 四、BP 与选手定位黑话（Draft & Roles）

### 1. 选手定位风格
- **吃土型射手 / 抗压射 / 工具人射**（如易峥、妖刀）：吃最少经济，打最多团战控制与承伤，给野核让经济。
- **大核射手 / 呆射**（如一诺、诗酒、钎城）：全队经济倾斜，后期大心脏接管比赛。
- **辅核**（如子阳、大帅、阿改、帆帆）：辅助拥有绝对指挥权，战术资源向其倾斜，是全队视野与进攻发起第一大脑。
- **战边**（Fly、轩染、清清、梓墨）：单带切后，个人手法极强。
- **坦边**（坦然、六点六、阿豆）：抗压承伤开团，团队之盾。
- **野核**（小胖、钟意、花海）：吃大量野区与中线经济，前期控图收割。
- **蓝领野 / 坦野**（夏侯惇、肉铠、阿古朵）：让野区经济给双C，充当前排抗伤和开团。
- **挂边**：中路清完线直接挂在边路草丛帮边路打人数差。
- **连体 / 连体婴**：辅助全程寸步不离保射手。

### 2. BP 博弈
- **以选代ban**：抢下对方绝活或关键体系核心，兼具己方补强与对方封锁。
- **摇摆位（中辅摇摆 / 边野摇摆）**：同一英雄适配多位置（如张良、王昭君走中或走游走），在BP中隐瞒真实分线迷惑对手。
- **吃分体系**：队伍胜率极高、熟练度拉满的绝活体系。
